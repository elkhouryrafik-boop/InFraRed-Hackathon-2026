# CoolSpend · Web

Photorealistic 3D Barcelona visualization of urban-cooling simulation results
(Infrared SDK UTCI heatmaps + proposed tree planting), built on
**Mapbox GL + deck.gl v9 (`MapboxOverlay`, interleaved) + Cesium Ion Google
Photorealistic 3D Tiles**.

Built to the recipe in `../infrared-sdk-deckgl-recipe.md`.

---

## Quick start

```bash
cd web
npm install
npm run dev          # http://localhost:5173
```

The app ships with a **placeholder bundle** in `public/web_bundle/`, so it shows
something immediately — even with no tokens (see *Graceful degradation* below).

```bash
npm run build        # tsc -b + vite build  (production)
npm run preview      # serve the production build
npm test             # vitest — pure logic units (format + colorscale + elevation)
```

## Tokens

Copy `.env.local.example` to `.env.local` and fill in:

```ini
VITE_MAPBOX_TOKEN=pk.xxxx        # https://account.mapbox.com/access-tokens/
VITE_CESIUM_ION_TOKEN=eyJxxxx    # https://ion.cesium.com/tokens
```

- **Mapbox** (free tier) — basemap + terrain DEM (for the ground-elevation lift).
- **Cesium Ion** (free tier: 1,000 sessions/mo) — proxies Google Photorealistic
  3D Tiles (asset `2275207`), EEA-friendly. One map mount = one session; the
  3D-tiles layer is mount-latched at module scope to stay inside quota.

`.env.local` is gitignored — never commit real tokens.

### Graceful degradation (never white-screens)

| Tokens present                | What you see |
|-------------------------------|--------------|
| Mapbox **and** Cesium         | Full Mapbox Standard basemap + Google photoreal 3D tiles, boundary cutout in the photogrammetry, UTCI heatmap drape, trees. |
| Mapbox only                   | Mapbox basemap + all deck.gl overlays. Notice: *"Add Cesium Ion token for photorealistic 3D."* |
| Neither                       | Flat dark deck.gl canvas + all overlays (heatmap, trees, boundary). Notice prompts for tokens. |

## What it renders (recipe mapping)

- **Map** — centred on `decision.site_center_lonlat`, pitch 55°, zoom 16,
  Mapbox `standard` style. Mapbox `show3dObjects` is disabled when Google 3D
  tiles are on (avoids z-fighting). `map.setTerrain()` is **never** called.
- **Photoreal city** — `Tile3DLayer` (interleaved) via Cesium Ion, zoom-gated /
  faded between zoom 13→15, mount-latched.
- **Boundary cutout** — hidden `SolidPolygonLayer` mask + `MaskExtension`
  `maskInverted: true`: photogrammetry is cut **inside** the site ring.
- **UTCI heatmap** — `BitmapLayer` from `utci_intervention.png` (default),
  toggle to `utci_baseline.png`, opacity slider (default 0.7),
  `bounds = [west, south, east, north]`.
- **Trees** — `ScatterplotLayer`, `radiusUnits: 'meters'`,
  `getRadius = crown_diameter_m / 2`; proposed use per-feature colour, existing
  use muted olive `[115,140,107]`.
- **Elevation lift** — Mapbox DEM sampled at the site centre + Barcelona geoid
  undulation → a column-major `modelMatrix` shared by every overlay so they sit
  on the photogrammetric ground.
- **HUD** — glassy top-left card: headline, rank-1 KPIs (trees, budget €,
  cooled m², €/m², feels-like peak baseline→intervention with Δ°C), scenario
  toggle, heatmap opacity, UTCI legend, disclaimer.

Color-scale (`src/lib/colorscale.ts`) and KPI formatting (`src/lib/format.ts`)
are **pure** (no deck.gl import) and unit-tested headless.

## Data contract — the "web bundle"

The app loads `public/web_bundle/`:

| File                     | Shape |
|--------------------------|-------|
| `decision.json`          | headline, backend, disclaimer, budget_eur, site_center_lonlat `[lon,lat]`, site_size_m, generated_at, `configurations[]` (rank, label, tree_count, cost_eur, cooled_footprint_m2, eur_per_m2, delta_utci_c, utci_baseline/intervention_mean/peak, species[]) |
| `boundary.geojson`       | FeatureCollection, one Polygon, `properties.kind="site_boundary"`, ring `[lon,lat]` (closed) |
| `trees.geojson`          | FeatureCollection of Points; props `{ kind: "proposed"\|"existing", species, crown_diameter_m, height_m, color: [r,g,b] }` |
| `utci_baseline.png`      | RGBA heatmap raster (already colorized) |
| `utci_intervention.png`  | RGBA heatmap raster (already colorized) |
| `bounds.json`            | `{ west, south, east, north }` — geographic bounds for both PNGs |

### Real data vs. placeholders

The included files are **dev placeholders** (Barcelona Eixample,
`2.1649, 41.3915`) generated by:

```bash
python web/scripts/make_placeholder_bundle.py
```

The **real** bundle is produced by the project's Python exporter into
`outputs/web_bundle/`. To use it, copy it over the placeholders:

```bash
# from the repo root, after the exporter has run
cp -r outputs/web_bundle/* web/public/web_bundle/
```

The app picks it up automatically on reload — the contract is identical.
