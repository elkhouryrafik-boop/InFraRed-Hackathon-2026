<objective>
Build the calibration study that ground-truths the ΔTmrt surrogate against real Infrared
UTCI — the existential keystone. Generate 10 deterministic, seed-pinned, coverage-swept
configurations spanning the surrogate's whole operating band (low→high canopy coverage),
run them LIVE through Infrared once and record every response to cache (D-01) so the fit is
reproducible offline and CI never burns the key. Compute RMSE + R² + an empirical error band
(D-04) for how well surrogate ΔTmrt — routed to UTCI via Plan 02's path — tracks measured
Infrared UTCI. Report ranking stability BOTH ways (D-05): a set-overlap headline (which of
the surrogate Top-3 stayed Top-3 under real UTCI, naming any rank swaps like "rank 1↔2")
PLUS a Spearman/Kendall τ over the full config set. Use a SEPARATE study SimBudget
(cap = n_configs + baseline = 11) so the headline "3 live calls" guarantee for the decision
artifact stays intact (D-03).

Purpose: VALID-01 (calibration RMSE/R²/band) + VALID-03 (ranking stability both ways).
This is the answer to "do surrogate rankings hold against measured UTCI?" — everything
downstream of Phase 5 depends on it. Honors D-01/02/03/04/05 and D-15 (live = real, recorded).
Output: coolspend/calibration.py + outputs/calibration_study.json + tests.
</objective>
