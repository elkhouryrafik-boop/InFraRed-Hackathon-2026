<objective>
Build `coolspend/optimizer.py` — the NSGA-II core (OPT-01) and the Top-3 real-UTCI validation
(OPT-03), composing the three Wave-1 outputs.

This is a tree optimizer, NOT the reference canopy optimizer. Adapt `nature_nsga2_coolstock.py`'s
pymoo NSGA-II setup (seed 42, SBX/PM, ElementwiseProblem, FloatRandomSampling) to a FIXED-LENGTH
vector of candidate tree coordinates. TWO objectives only (PROJECT.md decision):
  F1 = -thermal_relief(config)        (maximize cooling — minimize negative; spatial_engine surrogate)
  F2 = -ecological_score(config)      (maximize coherence — minimize negative; rules_engine)
ONE constraint:
  G1 = total_cost(config) - budget_eur ≤ 0   (reject/penalize over-budget configs)
Validity: trees placed via spatial_engine.is_valid_location stay out of buildings/streets/off-site.

The surrogate runs in the hot path (zero live SDK). After NSGA-II terminates, select_top3() picks
3 representatives and validate_top3_with_infrared() calls the SDK exactly 3× (SimBudget-guarded),
replacing each surrogate estimate with a labelled real UTCI delta.

Output: `coolspend/optimizer.py`, `coolspend/tests/test_optimizer.py`.
</objective>
