## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline results → outputs/*.json | Decision artifact written to disk and read by Phase 3 Gradio app |
| config metrics → public claims | Surrogate vs validated values must not be conflated in the artifact |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Repudiation | surrogate value presented as measured in the artifact | mitigate | Every config carries disclaimer + delta_tmrt_source; run_metadata flags surrogate +/-4C; validated_backend distinguishes mock vs live |
| T-02-16 | Tampering | JSON output | mitigate | json.dump only (no eval); deterministic seed-42 run is reproducible |
| T-02-17 | Information disclosure | save_outputs / main | accept | No secrets in the artifact; API key never reaches optimizer/main (stays in sdk_client live branch) |
| T-02-18 | Denial of service | matplotlib import/plot failure | mitigate | plot_pareto wrapped — JSON still written if plotting fails (pipeline never blocks on the PNG) |
