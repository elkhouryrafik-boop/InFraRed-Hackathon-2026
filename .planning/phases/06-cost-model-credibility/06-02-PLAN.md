<objective>
Apply a growth-horizon discount to the €/°C KPI (COST-05 / D-07..D-10): model a canopy growth curve (cooling fraction ramps ~20% at planting toward full canopy over ~25 years), discount future cooling benefit and OpEx at a 3.5% social discount rate (EU/UK Green Book) over a ~40-year functional-lifespan horizon, and route the discounted-ramped benefit into `cost_per_utci_degree` consistently with Phase 5's UTCI routing — preserving the existing dict keys, zero/negative-delta guard, dual units (€/°C + €/UTCI-hour) and [lo,hi] band.

Purpose: A tree does not deliver full-canopy cooling on day one. Counting day-one full benefit overstates cooling and understates €/°C. Ramping benefit over the establishment/growth curve and discounting future years is what makes the denominator defensible to an auditor.

Output: `GrowthDiscountParams` dataclass + `growth_cooling_fraction()`, `discounted_lifetime_degc()`, and `discounted_total_cost()` functions in `cost_model.py`; `cost_per_utci_degree` re-routed through them; a documented formula in the module docstring; tests; and a MOCKS.md row for the growth/discount assumptions.

```python
from dataclasses import dataclass

@dataclass
class GrowthDiscountParams:
    """Editable growth-curve + discounting parameters (COST-05)."""
    ramp_years: float = 25.0          # D-07: establishment→maturity duration
    initial_fraction: float = 0.20    # D-07: cooling fraction at planting
    discount_rate: float = 0.035      # D-08: EU/UK Green Book social discount rate
    horizon_years: int = 40           # D-09: tree functional lifespan

DEFAULT_GROWTH_DISCOUNT: GrowthDiscountParams

def growth_cooling_fraction(year: float, p: GrowthDiscountParams) -> float:
    """Effective cooling fraction in `year` since planting.
    Linear ramp from initial_fraction at year 0 to 1.0 at ramp_years, clamped to 1.0 after."""

def discounted_lifetime_degc(full_canopy_degc: float, p: GrowthDiscountParams) -> float:
    """Present-value-weighted equivalent °C: sum over years of
    full_canopy_degc * growth_cooling_fraction(y) / (1+r)^y, normalised by
    the discounted year-count so the result is an *equivalent steady °C* (D-10).
    Returns the discounted-lifetime equivalent mean-°C drop."""

def discounted_total_cost(config: dict, p: GrowthDiscountParams) -> float:
    """CapEx (year 0, undiscounted) + present value of OpEx over horizon at rate r,
    times tree_count. Consistent with total_cost() shape (reads config['tree_count'])."""
```
