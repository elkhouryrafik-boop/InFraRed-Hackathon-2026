Make the cost table per-city configurable through editable inputs instead of hardcoded constants (COST-04 / D-05, D-06). Output: `coolspend/cost_config.json`; `load_cost_table()` / `cost_table_from_dict()` in `cost_model.py`; Gradio cost inputs + threading in `app.py`; tests; and a human-verify checkpoint confirming live recompute.
