<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → process | INFRARED_API_KEY arrives via environment; must never be hardcoded or committed |
| process → disk cache | cache/infrared/*.json read back as UTCIResult; treated as our own deterministic output, not untrusted input |
| process → Infrared API (Phase 2+) | live UTCI calls cross to a third-party service; rate/cost governed by SimBudget |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | INFRARED_API_KEY handling | mitigate | Key read only from `os.environ`; never a literal in code; `.env` added to `.gitignore` in Task 1; key presence checked, value never logged |
| T-01-02 | Spoofing / Integrity | mock data presented as real | mitigate | Every mock UTCIResult carries `disclaimer="NOT MEASURED DATA"`; MOCKS.md row seeded; cached miss raises rather than silently serving mock |
| T-01-03 | Denial of Service / cost | live UTCI calls in a loop | mitigate | SimBudget caps live calls and raises past cap (SDK-03); live dispatch raises NotImplementedError until explicit Phase 2 validation function |
| T-01-04 | Tampering | malicious cache JSON | accept | Cache is process-authored under our own dir; no eval/exec used to parse (json.loads only); low-value local target |
</threat_model>
