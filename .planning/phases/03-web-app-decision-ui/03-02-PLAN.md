| Boundary | Description |
|----------|-------------|
| Browser/UI -> on_submit | User polygon + budget + backend selection cross into the app |
| on_submit -> run_decision (live) | UI can trigger live Infrared calls when backend=live |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Info disclosure | UI banner / call log | mitigate | Never render INFRARED_API_KEY; banner shows only backend name + disclaimer; call_log is SimBudget labels only |
| T-03-06 | Tampering | polygon textarea | mitigate | Parsing delegated to parse_site_geojson (json-only, schema-validated) in app_pipeline; app.py never eval's input |
| T-03-07 | DoS | live backend via UI | mitigate | SimBudget cap (3 live calls/run) enforced inside run_decision; backend defaults to mock |
| T-03-08 | Repudiation | which UTCI is real | mitigate | Per-row provenance disclaimer + global banner make mock-vs-live explicit (honesty contract) |
</threat_model>
