Build the UI-agnostic core for the CoolSpend web app: a single `run_decision()`
function that drives the full pipeline (optimize -> validate Top-3 -> TOPSIS) and
returns a structured result, plus a `render_before_after()` matplotlib visual. Both

stdout.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI text -> run_decision | User-supplied GeoJSON string crosses into parsing |
| run_decision -> sdk_client (live) | UI-triggered run can reach live Infrared calls |
| env (INFRARED_API_KEY) -> process | Secret lives in env only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | parse_site_geojson | mitigate | json.loads ONLY, never eval/exec; validate schema before use (CONVENTIONS Rule 4) |
| T-03-02 | DoS | run_decision live path | mitigate | SimBudget(max_live_calls=3) caps UI-triggered live Infrared calls per run |
| T-03-03 | Info disclosure | INFRARED_API_KEY | mitigate | run_decision never reads, logs, or returns the key; only flips INFRARED_BACKEND |
| T-03-04 | Info disclosure | call_log returned to UI | accept | call_log contains only SimBudget call labels (no secrets); reviewed format |
</threat_model>
