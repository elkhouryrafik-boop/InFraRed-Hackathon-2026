Real shipped pipeline (decode is trees, not scaffold):
  1. BASELINE: sdk_client.get_baseline_utci() (mock|cached|live)
  2. OPTIMIZE on SURROGATE: optimizer NSGA-II / TreeBudgetProblem — N_TREES=12, chromosome = 2*N_TREES floats (x_m,y_m per tree); 2 objectives (F1=-thermal_relief, F2=-ecological_score), 1 budget constraint; surrogate = spatial_engine.delta_tmrt_surrogate (no SDK call in hot path)
  3. SELECT TOP-3: select_top3 → labels MAX_THERMAL_RELIEF / MAX_ECOLOGICAL / BALANCED
  4. VALIDATE TOP-3 with real UTCI: validate_top3_with_infrared (SimBudget cap = 3 live calls)
  5. RANK €/°C: topsis_rank — primary sort ascending cost_per_utci_degree, TOPSIS (weights default (0.6,0.4)) as tie-break
  6. EMIT: save_outputs → outputs/top3_configurations.json + audit_record.json + pareto_front.png

- per-config headline KPI lives at config["cost_per_utci_degree"]["value"] (unit "EUR/degC"), NOT a flat eur_per_utci_degree field (that field is None)
- each config carries tree_count=12, delta_tmrt_c (surrogate), validated_utci_c (mock until live), topsis_score, and a `disclaimer` string
- run_metadata: algorithm "NSGA-II (pymoo 0.6.1)", site "Plaça dels Àngels, Barcelona", seed 42, surrogate label
